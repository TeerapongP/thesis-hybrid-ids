======================================================================
4. SCHEMA AND FIDELITY
======================================================================
Rows are in the scaled 92-feature space of cicids2017_behavioral_features_*.parquet. Raw values
are drawn first, then scaled with the real train-split min/max (the pipeline's MinMaxScaler,
reconstructed from data/processed/behavioral). Verification on 2,000 real test rows: max abs
difference between this scaling and the pipeline's scaled values = 2.22e-16.
Real columns also exceed [0,1] slightly because test rows fall outside the train range; no clipping.

Tier A, MODELLED per attack class (drawn from the profile's distributions):
  Destination Port, Flow Duration, Total Fwd/Backward Packets, Fwd/Bwd Packet Length Mean/Std,
  PSH/SYN/FIN/RST/ACK counts (from handshake outcome), Init_Win_bytes_forward/backward,
  Init_Win_*_missing flags (backward missing when the target never replies, as in real data).
Tier B, DERIVED deterministically from tier A (exact given the primitives):
  Total Length Fwd/Bwd, Subflow*, Flow Bytes/s, Flow Packets/s, Fwd/Bwd Packets/s, Down/Up Ratio,
  Average Packet Size, Avg Fwd/Bwd Segment Size, Packet Length Mean/Std/Variance.
Tier C, HEURISTIC approximations (plausible, not drawn from real attack captures):
  Fwd/Bwd Packet Length Max/Min (mean +/- 2 std, capped at 1460), all IAT Mean/Std/Max/Min and
  Fwd/Bwd IAT Total (mean = duration / gaps, std = cv * mean with cv drawn per profile),
  Fwd/Bwd Header Length and Fwd Header Length.1 (20 bytes per packet), act_data_pkt_fwd (n_fwd - 2),
  Fwd PSH Flags (1 when any PSH), min_seg_size_forward (20).
Tier D, PLACEHOLDER defaults, not modelled:
  Active Mean/Max/Min = flow duration, Active Std = 0, all Idle* = 0 (each flow is one active period),
  Bwd PSH Flags, Fwd/Bwd URG Flags, URG/CWE/ECE Flag Count = 0,
  all six Fwd/Bwd Avg Bytes/Packets/Bulk and Bulk Rate columns = 0.
Tier E, WINDOWED behavioral columns (12): computed, not drawn, with the real extractor's own
  _sliding_window_features and compute_failed_flag. Caveat: windows see only overlay flows from the
  same synthetic source IP, never the benign background. Synthetic sources use TEST-NET-3
  (203.0.113.0/24) or 10.20.0.0/16, so they do not collide with real CICIDS-2017 hosts.
Metadata, not model input: inject_id, inject_timestamp, synthetic, attack_class, campaign_id,
  src_ip, dst_ip, technique_id/name, tactic, Label ('SYNTHETIC'). The four CTI-encoded columns are
  omitted: they are not detection-model input (CLAUDE.md) and encodings were fit on real labels.
MITRE notes: data_exfil has no matching row in config/mitre_mapping.csv, so technique is empty.
  credential_stuffing uses T1110 (parent); T1110.004 is not in the mapping file.
Fidelity limit: the five profiles are hand-set distributions informed by attack mechanics, not fitted
  to real captures. Treat detector recall on this overlay as a measure of timing and plumbing, not
  as evidence of real-world detection performance.

======================================================================
5. COMPUTING MTTD FROM inject_timestamp
======================================================================
inject_timestamp is set once at generation (flow start time, UTC, tz-aware) and never recomputed.
Per flow:      MTTD_flow = detected_at(inject_id) - inject_timestamp, where detected_at is the time
               the pipeline first raised an alert for that flow. Join alerts to the overlay on inject_id.
Per campaign:  MTTD_campaign = min(detected_at over the campaign's flows) - min(inject_timestamp over
               the campaign). This is the analyst-relevant figure: how long the attack ran unseen.
Report the mean (and median) across detected campaigns per attack_class. Campaigns with no alert are
misses: count them separately; do not drop them silently or assign them an MTTD.
Code: mttd_seconds(overlay, detections, per='flow'|'campaign'), detections = [inject_id, detected_at].
Worked example (HYPOTHETICAL detection time, to show the arithmetic):
  inject_id inj-c2_beacon-001157 has inject_timestamp 2026-01-01T00:05:40.344767+00:00.
  Suppose the first alert for it is at 2026-01-01T00:05:47.844767+00:00.
  MTTD_flow = 2026-01-01T00:05:47.844767+00:00 - 2026-01-01T00:05:40.344767+00:00 = 7.5 s.
