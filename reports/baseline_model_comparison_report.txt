STEP 6: how to read this
======================================================================
  These are IN-DATASET numbers on a split the models trained against, and
  CICIDS-2017 saturates there: differences of a few thousandths of F1 do not
  establish that one model is better. The metric that separates candidates in
  this thesis is zero-day LOAO, which this script does not run.
  Wall-clock is not a like-for-like comparison either. scikit-learn has no GPU
  backend, so Random Forest is CPU-bound by the library, not by configuration.
  What this run does settle is the previously unanswerable question of whether
  an untested alternative is dramatically better on the same data. It is not a
  reason on its own to replace Random Forest.
