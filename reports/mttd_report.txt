STEP 4: MTTD with the campaign-initial flow removed
==========================================================================
  Every campaign's FIRST flow carries an all-zero behavioral vector -- physically
  correct, since a source IP has no prior window activity -- and the deployed rule
  scores those flows far above threshold, so the first flow is detected in every
  single campaign and MTTD collapses to the scoring latency. That makes the headline
  MTTD a measurement of the generator's window initialization, not of timeliness.
  This variant drops each campaign's earliest flow and asks the harder question: once
  that free detection is removed, how long does the campaign run unseen?

STEP 6: how to read this, and how not to
==========================================================================
  The detection rate above is NOT detection evidence. The overlay's distributions are
  hand-set from attack mechanics rather than fitted to real captures, so it measures
  whether the rule fires on flows shaped like this -- nothing about real traffic.
  MTTD is conditional on detection. Undetected campaigns are counted in their own
  column and given no MTTD; averaging a miss as a slow detection would flatter the
  system precisely where it fails.
  The headline per-campaign MTTD in STEP 3 is DEGENERATE and must not be quoted as a
  result: the first flow of all 228 campaigns is detected, so it equals the scoring
  latency by construction. Cite STEP 4 instead, and state that it excludes each
  campaign's first flow and why.
  Per-flow MTTD collapses to the scoring latency for the same reason.
  One more measured limitation of the overlay itself: its behavioral columns are far
  weaker than real traffic's. conn_count_1m tops out at 0.014 against 1.0 in the real
  unified test split, and uniq_dport_count_1m at 0.32 against 1.0. The synthetic port
  scan is much less aggressive than a real one on exactly the features Option A added,
  which is a concrete reason -- not just a caveat -- that detection rates here do not
  transfer.
